Number Quest is a simple number guessing game developed in C language as a part of our FOCP-I mini project.

Features
- Random number generation
- Multiple difficulty levels
- Limited attempts to guess the number
- Hints to guide the player
- Score tracking
- Simple and interactive gameplay

How to Compile and Run:-
1. Open the project folder in VS Code.
2. Open the terminal.
3. Compile the program using:
     gcc -Wall number_quest.c -o number_quest
4. Run the program using:
     ./number_quest
